# FB-23 — football match centre

**Purpose:** live World Cup 2026 match centre with score, events, win probability, venue, H2H, watch panel and match FAQs.

## Findings

| # | Severity | Category | Finding | File |
|---|---|---|---|---|
| 1 | High | States | Invalid ids render a blank page; query failures without a payload have no retry UI; no route error boundary. | `football.match.$id.tsx` |
| 2 | Medium | Tokens | Page mixes `bg-black`, `white/*`, `gray-*` with the token system. | page |
| 3 | Low | A11y | Decorative icons/spinners unlabelled; watch disclosure has no `aria-controls`; back link under 44 px; card links lack focus rings. | page |
| 4 | Low | SEO | No OG site name; redundant fixture ternaries. | head |

## Fix

1. Shared error/empty states, invalid-id handling, query retry and route error boundary.
2. Replace route-owned `black`/`gray`/`white` classes with tokens; keep live-red accents.
3. Label loading, hide decorative icons, connect disclosure panel, 44 px controls, focus rings.
4. Add OG site name; simplify head.
