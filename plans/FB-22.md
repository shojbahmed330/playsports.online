# FB-22 — football hub

**Purpose:** the main football landing page: live/2026 views, archive World Cup browser, groups, knockout bracket and modals.

## Findings

| # | Severity | Category | Finding | File |
|---|---|---|---|---|
| 1 | High | States | Archive queries can fail silently and fall through to “data coming soon”; no retry, no route error boundary. | `football.index.tsx` |
| 2 | Medium | Semantics | Nested clickable `div` wrappers around match cards only dismiss a hint; keyboard users cannot trigger them. | bracket columns |
| 3 | Medium | A11y | Favourites button loses its accessible name on mobile; tab buttons lack `aria-pressed`; collapse control lacks `aria-expanded`. | page |
| 4 | Medium | Tokens | Route-owned UI mixes hardcoded `gray-*` colours with the token system. | page |
| 5 | Low | Cleanup | Unused imports (`applyFilter`, `uniqueTeams`, `useMyTeams`); local empty-state duplicate. | top |
| 6 | Low | SEO | No OG site name; loading state not announced. | head/skeleton |

## Fix

1. Query error state with retry and a route error boundary.
2. Move hint dismissal into the match-card handler; remove non-interactive click wrappers.
3. Accessible favourites/tab/collapse controls; announce loading.
4. Replace route-owned `gray-*` with tokens; keep stage gradients.
5. Remove unused imports and the local empty-state duplicate.
6. Add OG site name.
