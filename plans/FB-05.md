# FB-05 — football competition overview

**Purpose:** main landing page for a competition: hero/countdown, facts, honours, scorers, news, H2H and quick links.

## Findings

| # | Severity | Category | Finding | File |
|---|---|---|---|---|
| 1 | High | Hydration | `nextLabel` is locale/timezone-formatted during SSR from live data; server and client can disagree. | `football.$comp.index.tsx` |
| 2 | Medium | States | Scoreboard errors are ignored; an error looks like an off-season and shows the recap. | page |
| 3 | Low | States | Bare not-found; no route error boundary. | route |
| 4 | Low | A11y | Quick-link arrow icons are announced; quick links lack focus rings. | `QuickLinks` |

## Fix

1. Mount-gate `nextLabel` so SSR omits local time and hydration adds it.
2. Show a retryable scoreboard error; suppress the off-season recap on error.
3. Shared not-found/error boundaries.
4. Hide arrow icons, add focus rings.
